Options

How to use Compress PDF

Reduce PDF file size with lossless stream and font compression and cleanup of unused objects. Process multiple files locally and download the results.

  1. Choose one or more PDF files.
  2. Run Compress files to optimize each PDF on your device.
  3. Check the actual size reduction and download individual PDFs or a ZIP.

Images are not downsampled. Already optimized PDFs may stay the same size; the original is kept when it is smaller.

Files and passwords stay on your device. Download results to keep a copy.
